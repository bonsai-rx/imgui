## About

`Bonsai.ImPlot` provides operators for composing real-time 2D plots using [ImPlot](https://github.com/epezent/implot) in the [Bonsai visual reactive programming language](https://bonsai-rx.org).

## How to Use

To use `Bonsai.ImPlot` for visual reactive programming, please install this package using the [Bonsai package manager](https://bonsai-rx.org/docs/articles/packages.html).

## Additional Documentation

For additional documentation and examples, refer to the [official Bonsai.ImGui documentation](https://bonsai-rx.org/imgui).
