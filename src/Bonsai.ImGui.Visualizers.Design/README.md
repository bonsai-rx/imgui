## About

`Bonsai.ImGui.Visualizers.Design` provides visualizer operators that initialize a Dear ImGui context in the [Bonsai visual reactive programming language](https://bonsai-rx.org). It is the recommended starter package for [Dear ImGui](https://github.com/ocornut/imgui) and [ImPlot](https://github.com/epezent/implot) workflows.

## How to Use

To use `Bonsai.ImGui.Visualizers.Design` for visual reactive programming, please install this package using the [Bonsai package manager](https://bonsai-rx.org/docs/articles/packages.html).

## Additional Documentation

For additional documentation and examples, refer to the [official Bonsai.ImGui documentation](https://bonsai-rx.org/imgui).
