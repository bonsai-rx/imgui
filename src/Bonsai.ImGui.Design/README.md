## About

`Bonsai.ImGui.Design` provides base classes for hosting [Dear ImGui](https://github.com/ocornut/imgui) visualizers in the [Bonsai visual reactive programming language](https://bonsai-rx.org).

## How to Use

To use `Bonsai.ImGui.Design` for visual reactive programming, please install this package using the [Bonsai package manager](https://bonsai-rx.org/docs/articles/packages.html).

## Additional Documentation

For additional documentation and examples, refer to the [official Bonsai.ImGui documentation](https://bonsai-rx.org/imgui).
